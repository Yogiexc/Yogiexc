## About

I'm Bryan.

An Informatics student who enjoys turning ideas into software, breaking things apart, and figuring out how they work.

I don't have everything figured out yet.

And I don't think I need to.

I'm interested in **backend systems, web development, APIs, databases, and the space between an idea and something that actually works.**

Most of what you'll find here is a collection of things I'm building, experimenting with, and learning from.

> **I leave traces, not explanations.**

---

## What I'm Building

```text
Ideas
  ↓
Questions
  ↓
Experiments
  ↓
Failures
  ↓
Better understanding
  ↓
Something that works
```

I prefer learning by building rather than waiting until I know everything.

Some projects will be polished.

Some won't.

Both are part of the process.

## Selected Work

### Backend

**Enterprise REST API — Go**

Exploring backend architecture, REST principles, authentication, and the problems that appear when an application starts becoming more than a simple project.

**FastAPI API Monitor**

An experiment around API monitoring, asynchronous programming, and understanding how services communicate with each other.

**PHP Native REST API**

Going back to the fundamentals — HTTP, routing, requests, responses, and what frameworks are actually abstracting away.

---

### Frontend

**Svelte / Vue / React Experiments**

Different approaches to building interfaces.

Not trying to find the "best" framework.

Trying to understand which tool makes sense for which problem.
